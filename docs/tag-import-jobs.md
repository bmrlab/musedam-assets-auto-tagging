# 大标签树导入任务与长关键词导出

## 用户流程

少量手动批量创建继续直接提交，只发送本次新增路径。输入 JSON 超过 512 KiB 时，在浏览器提示改用 CSV / Excel 导入，避免把大请求送到业务网关。

表格导入仍保留只读预览、合并/覆盖选择及覆盖确认。文件上限 5 MiB，浏览器先通过已有对象存储直传文件，再发送上传记录 ID、层级、导入方式、语言和已确认跳过的行号。文件不会作为 Server Action 请求体重复上传；本地 S3 代理继续复用每片 512 KiB 的上传实现。

确认后创建持久任务，界面显示上传中、排队中、后台导入和重新连接状态，不展示虚构的百分比。可关闭窗口；重新打开时只读查询原上传回执或本人正在执行的任务，恢复进度及结果。结果包含成功数和失败明细。网络中断只重试有限次状态查询，不重发导入操作；无法查询时提示重新打开窗口核对。

## 服务端与一致性

- `POST /api/tags/imports` 的 `upload`、`precheck`、`submit` 均验证当前登录和既有应用管理权限；文件上传 URL 使用 private ACL，上传回执绑定当前用户和团队。只接受服务端签发的记录 ID，不接受任意对象 URL。
- 读取文件时校验实际大小和 SHA-256，防止预览后换文件。原文件只存对象存储；`TeamConfig.tag-import-upload:<uuid>` 保存元数据和确认选项，不存文件正文或登录 token。上传记录 30 分钟内可提交。
- 提交在上传记录行锁内创建 `TaggingQueueItem`，`extra.jobKind=tag-tree-import`、`taskType=manual`、无素材关联。并发提交或 POST 回包丢失后重复确认返回同一任务号；已提交记录不能改导入方式、层级、语言或跳过行。
- worker 只执行与任务号匹配的已授权回执。身份及语言通过 server-only 的异步上下文传给原导入 actions；HTTP 请求不能设定这个上下文。授权在提交时确认，不持久化主站登录凭据，也不信任浏览器传入的权限布尔值。
- 执行复用 `importTagTreeAction`、原团队锁、主站同步导入回执及 `tag-mutation-pending` 恢复机制，保留本地标签 ID、人工 AI 配置和历史关联。导入任务不走素材识别或扣点流程，复用现有生产队列槽位。
- 中断或超时的导入不自动重新排队，避免重放覆盖操作。资产控制面板的查询、统计和单个/批量重试仅作用于有素材关联的任务，不能从这些入口重放管理类导入。任务失败后先核对主站和本地结果，再明确发起新导入。
- `GET /api/tags/imports?jobId=...` / `?uploadId=...` 只读查询本人、当前团队的任务；不传 ID 时查询本人最近一个 pending/processing 导入。回执查询不需要重新提交业务操作。
- 日志关键词：`Tag import job accepted`、`Tag import job started`、`Tag import job finished`、`Tag import job failed`，按 `jobId` 和 `teamId` 关联原 `Tag import phase` 日志，不记录文件正文或凭据。

## 发布和存储配置

无需新增 migration 或 user 服务改动。先升级所有自动打标 worker，再升级 web/API，之后启用该页面；旧 worker 不认识新任务类型。权限沿用已有主站布尔通信和应用管理权限，无新增主站发布依赖。

复用现有 S3/OSS 配置。发布时核对浏览器 PUT 的 CORS、签名 ACL 头和服务端私有读取。`tag-imports/`（位于现有 `S3_FOLDER` 下）必须禁止匿名读取，不应沿用素材图片的公开读取策略；建议为该临时前缀配置 7 天过期清理。代码不会自动修改桶策略或生命周期。生产直传和鉴权须实际联调，组件样例与 mock 测试不能替代。

## 长关键词的产品规则

匹配/排除关键词列表超过单元格预算时自动按完整词拆为续行，每格最多 30,000 个 UTF-16 单元，不截断、不把一个词拆成多个词；CSV/XLSX 使用相同表示，避免用户经 Excel 打开 CSV 时再丢内容。

续行重复同一标签 ID 和完整路径，`关键词续行=1`；其他配置只写首行。普通文件不增加续行列。界面说明该含义，实际拆分时提示增加的续行数。编辑后需保持同一标签各行相邻并保留身份、路径及标记；导入按组重新合并、去重，普通重复 ID 仍报错。

任何续行身份、路径、标记或关键词校验失败，会拒绝该标签整组数据，不会应用前几行组成的不完整列表。其他合法标签仍可按原预览确认流程导入。单个关键词仍按现有 100 字符规则校验；列表总长与单个词的长度是两个不同限制，不能靠切词绕过。

## 验证范围

覆盖文件直传复用、私有 ACL、实际大小/摘要、团队与用户隔离、重复提交、只读恢复、状态重连、确认选项绑定、覆盖确认、长关键词 CSV/XLSX 往返和错误续行整组拒绝。独立临时 PostgreSQL 验证 20 个并发提交仅产生一个任务，并运行既有导入事务/锁回归。隔离库运行入口为 `TAG_IMPORT_TEST_DATABASE_URL`，仅允许本地新建 `tag_import_test_*` 库，禁止指向业务库。

已用真实弹窗组件的模拟样例检查亮/暗主题、后台状态、关闭行为及导出说明；样例不连接生产文件、主站或真实队列。
